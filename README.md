# Unbanded — the Vencord of BAND (band.us)

> A modded client for BAND, inspired by [Vencord](https://github.com/Vendicated/Vencord) (the Discord mod: plugins + themes + settings on top of the official client): **plugins, themes, custom CSS, and `/slash` commands** directly in band.us via a userscript.
> Formerly **Band Tamper** — renamed **Unbanded** in v1.6.0 (persisted data and plugins remain compatible).

Unbanded doesn't modify BAND itself: it's a **customization layer** on top of the web client — just as [Vencord](https://github.com/Vendicated/Vencord) adds plugins + themes + settings on top of [Discord](https://discord.com), Unbanded adds **plugins + themes + CSS + `/slash` commands** on top of BAND. See [releases](https://github.com/HYPE115/Unbanded/releases) for version history, and [issues](https://github.com/HYPE115/Unbanded/issues) to report bugs.

## What it brings (Vencord-style)

- **🔌 Plugins** — JS plugin loader (from URL or `.js` file), enable/disable, persistence, and auto-reload on startup. Documented API to write your own (see [Add Your Own Plugins](#add-your-own-plugins)).
- **🎉 Built-in plugins** — 30+ instant commands: reaction GIFs (`/hug`, `/cuddle`, `/slap`, `/kiss`…), local mini-games (`/8ball`, `/roll`, `/coin`, `/choose`), tools (`/remind`, `/shrug`, `/tableflip`, `/lenny`), and `/pat` (authentic pet-pet GIF).
- **🎨 Themes** — gallery of 10 themes, JSON import/export, instant application (CSS `--btt-*` variables), applied across band.us including the chat window (header, message bubbles, composer).
- **💅 Custom CSS** — built-in editor, applied live across all of band.us.
- **⌨️ `/slash` commands** — executed via Enter, Discord-style autocomplete (`/` + start → popup, `↑/↓` + `Tab`/`Enter`), `↑/↓` history, aliases (`/h` → `/help`…), detailed help (`/help <cmd>`).
- **😀 Emoji picker** — 😀 button docked near the chat input: category tabs, **search button/field** (instant EN/FR filter, `Enter` inserts the first hit), recently-used emojis persisted locally — fully offline, no network.
- **⚙️ Settings page** — tabs: General, Plugins, Themes, CSS, About. Gear button ⚙ docked in the band.us header, shortcuts `Ctrl+,.` / `Esc`, console API `window.Unbanded`.

## Settings page

- **General** — startup toast (on/off), toast duration (3/5/8/12 s), full configuration export/import in JSON (plugins + themes + CSS + options, ideal for changing browsers) and "Reset all" button.
- **Plugins** — plugin list with *active/inactive* and *source* (Built-in / URL / File) badges, plus adding plugins **by URL** or **by imported `.js` file** (code stored in `BTTStore` and **auto-reloaded on next startup**).
- **Themes** — gallery of **10 built-in themes** (Violet by default, Minuit, Dracula, Nord, Catppuccin Mocha, Monokai, Sunset, Ocean, Forest, Light) with color preview, one-click application (CSS `--btt-*` variables on the page + panel restyle), and **theme import by URL or `.json` file** + JSON export of any theme.
- **Custom CSS** — CSS editor applied **live** to band.us (element `<style id="bt-custom-css">`), with non-persistent preview, save, and reset. CSS survives reloads.
- **About** — version, statistics (plugins/commands/themes), credits, and license.

### Theme format (JSON import)

```json
{
  "name": "My theme",
  "author": "me",
  "version": "1.0.0",
  "colors": {
    "accent": "#ff7ac6", "accentHover": "#f45fb2",
    "bg": "#2b1d33", "surface": "#241729", "surface2": "#3a2744",
    "text": "#ffe9f6", "muted": "#c7a3bd", "border": "#4a3357"
  },
  "css": "/* optional: CSS applied to band.us with this theme */"
}
```

All colors are **optional** (missing ones fall back to the default violet); format `#rgb` or `#rrggbb`. The `css` field lets you push the theme further (band.us overlays). Note: URL import depends on band.us's CSP (`connect-src`) — if the remote domain is blocked, use file import instead.

## Reaction plugin (reaction bank)

`src/plugins/reactions.js` is a built-in plugin that sends GIFs via commands like `/hug`, `/cuddle`, `/slap`, `/kiss`, etc. Instead of fetching at runtime from `api.waifu.pics` (network, CORS — the API and even the domain are now dead/repurposed), the assets live in the reaction bank `src/assets/reactions/`, downloaded **once at build time**:

- **18 commands** — `hug`, `cuddle`, `slap`, `tickle`, `kiss`, `poke`, `bonk`, `dance`, `wave`, `blush`, `smile`, `smug`, `cry`, `nom`, `yeet`, `wink`, `laugh`, `happy`
- **10 GIFs per command** — real anime GIFs scraped from [nekos.best](https://nekos.best) by `tools/fetch_reaction_gifs.py` (each folder is cleared first; 10 GIF89a files, `01.gif`…`10.gif`)
- **Manifest** — `src/assets/reactions/manifest.json` (18 commands × 10 files)
- **Runtime loading** — the bank is fetched from an **absolute CDN URL** (jsDelivr → Statically → same-origin fallback), *not* from a path relative to `band.us`: the client is a SPA and answers unknown paths with its HTML fallback and an HTTP 200, which made `response.json()` throw (`GIF unavailable (Reaction bank not found)`). Manifests are validated (must parse as JSON) and GIFs are validated (must have an image content type) before being used, and the filename is sanitized.
- **Fallback** — `tools/build_assets.py` (Pillow) can regenerate tiny 64×64 placeholder GIFs fully offline if you can't reach the API. If every source fails, a toast explains why and nothing is sent.

The `/pat` command remains dedicated to `pet-pet.js` and is untouched.

## ⚠️ Adapting to BAND selectors

BAND doesn't publish a public API and its DOM evolves. The file `src/core/adapter.js` contains **selectors** (`SELECTORS.input`, `SELECTORS.sendButton`, `SELECTORS.avatar`, `SELECTORS.currentChannel`, …) that may not exactly match your client version.

If message sending or avatar reading doesn't work:
1. Open DevTools (F12) on band.us,
2. Inspect the input field, the send button, avatars,
3. Update selectors in `src/core/adapter.js`,
4. Run `node build.js` again and reinstall the userscript.

## Demo mode

If you open the script outside of band.us, a "demo mode" banner appears and lets you test the plugins panel and the `/pat` command without sending real messages.

## Build (regenerate the userscript)

```bash
node build.js
```

Requires Node.js. The result is `unbanded.user.js`.

The sources are concatenated **in the order defined in `build.js`** (`src/main.js` is always last). Handy dev scripts:

```bash
python tools/fetch_reaction_gifs.py           # scrape 10 GIFs/command from nekos.best (build time)
python tools/gen_reaction_bank.py             # regenerate the bank manifest.json
python tools/build_assets.py                  # fallback: regenerate the GIFs offline (Pillow)
```

> nekos.best enforces a global rate limit (~200 requests/min): `fetch_reaction_gifs.py` paces itself and fails fast on a long `Retry-After` — just rerun it later for the missing commands (`python tools/fetch_reaction_gifs.py hug cry`).
